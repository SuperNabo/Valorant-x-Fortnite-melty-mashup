# Tactical Spike Build

A high-intensity game mashup bringing precise VALORANT tactical gunplay, buy phases, and spike-plant mechanics directly into Fortnite's building and editing sandbox.

## Features
- **VALORANT Tactical Gunplay**: Accurate recoil, one-tap headshots, and round-based economy.
- **Fortnite Building & Editing**: Place walls, ramps, and edits during tactical firefights and spike retakes.
- **Spike Plant Mechanics**: Attackers plant the spike, defenders defuse.
- **Companion Integration**: Reads asset folders from local installations of Fortnite and VALORANT via Melty.
